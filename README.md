# 碎影江湖 · 酒馆插件

给角色卡「碎影江湖 · 资料片 刃影迷局」配的 SillyTavern 扩展。分**土著**与**玩家**两种模式：土著是这个世界的人（异人眼里的 NPC），玩家是进入江湖的异人。

## 安装

酒馆 → 扩展 → 安装扩展，填：

```
https://github.com/Zaiyebuzuoyouqingdetiangou/syjh
```

以后更新：面板右上角齿轮 →「版本」，检测更新、先看新版写了什么、一键更新并刷新。

装好后聊天界面右下角会出现一枚印章：轻点打开面板，长按看速览，按住可以拖到别处。也可以输入 `/碎影` 打开。剧里有了时辰，印章就变成一个小时辰盘：外圈是一天的天色，现在的时辰那一个字停在外圈对应的位置，中间的天光、天气、月亮太阳跟着变（关掉「聊天跟着天气时辰变」也照样变）。

## 有什么

| 页 | 土著 | 玩家 |
| --- | --- | --- |
| 舆图 / 地图 | 一张手绘舆图：山川、官道、北境风雪、西域黄沙；你在哪盖一枚朱砂印，走过的路一笔笔连起来。开图先看走过的那一块，走得越远地图越大；剧情里新出现的城镇自动落在所属大区，标「新」。可以拖动、缩放，点城镇看详情，下面另有地名录。点开任何地方：此地风物、去处、归属与势力、在场和见过的人、能做的事、物价与买卖、传闻与事件、你的足迹 | 深色网格地图、定位标记、移动路线、探索进度；其余同左，叫法换成地点介绍、NPC、可交互、商店与物价、探索记录 |
| 人物 / 名册 | 按和你的关系分栏：在场、相熟、不睦、按势力、全部，画像排成格子，置顶的排最前；主角自己不会当成 NPC 列进来，旁人按姓氏叫你「某大姑娘」「某公子」也认得出（认错了在人物页点「这是我」或「不是我」改过来，同名的几条一起改）。记岔了的人可以从名册删掉，同名的能一起删，户帖页里随时恢复。没报过名的人只显示样貌；自称、化名、真名一层层解锁。点开人物：称呼与底细、对你（厌恶到亲密六档）、喜好与忌讳、关系网、近况、来往与亲密（按日期折叠） | 好感出数值（−100 到 +100），其余同左 |
| 行囊 / 背包 | 上面是钱袋；物件按兵器、衣饰、药物、秘籍、吃食、凭证、杂物分格子，点开看来历；信物和银钱（存款欠账、账目、成交、手记）各一栏 | 同左，物品带品质色 |
| 江湖 | 往事簿（不花钱，跟着聊天自动把原文分段记成往事，每段几楼可以自己设）、风声与通缉、各方态度、时局、告示、百晓阁 | 通缉、阵营声望、世界公告、告示栏、情报 |
| 异闻 / 论坛 | 异人在他们的论坛上议论你——只有读者看得到 | 江湖论坛，分综合、攻略、交易、组队、八卦、求助几个板块；能自己发帖、回帖，别的玩家会跟帖 |
| 户帖 / 角色 | 身份、所学武功、身体、心事；户帖可以让 AI 从人设、角色卡、世界书和你说过的话里补全 | 属性、状态、武学、任务、成就 |

## 像一个游戏

打开面板就是一整块游戏画面（土著参考太吾绘卷的水墨卷轴，玩家是深色网游界面）：

- **顶栏**：你的画像、银钱声名（玩家是气血内力），右边是剧里的日期、时辰、天气和节气。
- **近况卡**：最后一条回复底下一张卡，写你此刻怎么样：画像、日子时辰、身在何处、身上多少银子；衣、食、住、行、身、心六格各一句话和一道刻度，要紧的那格变红；体质（千杯不醉、先天不足……）、眼下的状态（伤、病、醉、中毒、药力，带着还要多久），还有最拿手的几门武功。收起时是你的小画像和一个气泡：颜文字加一句心声，底下挂着正在生效的状态。玩家模式是状态面板：气血、内力、体力、饱食四条，增减益和技能栏。设置里能选状态随时辰变化（几个时辰没吃会饿、熬久了会乏，正文里会带出来），或者只照剧情写的记。
- **此地**：你此刻所在的地方，水墨小景；这里站着谁（画像框，点开看人物）、能去哪、能做什么；传闻、手头的事、新来的书信。
- **人物窗**：画像、名号、身份、特性、待你如何、此刻在做什么。「生平」里按日子排着你和他的来往，还有你看不见的「暗里」——只有看戏的人知道。可以给人物换上自己的画像。
- **手改关系**：人物窗里点「待你」，能改成六档里的一档或自己写一个词、玩家改好感数、写明跟你是什么关系；之后剧情里态度又变了，以剧情为准。没跟你打过交道却记了态度的人，名册里会提醒，一键清掉。
- **对人能做事**：人物窗里一排动作。人在跟前，能搭话、送礼、请教、切磋、托付、相约；不在跟前，能登门拜访、写信、托人送礼、约见、捎口信、打听近况。点了把这件事放进输入框，你改了再发。送礼从行囊里挑，写着他喜好什么、犯什么忌；写信有信笺，寄出去过一两日会有回信。
- **过日卷轴**：跨进新的一天，弹一张卷轴：这一日的章回回目、节令风物、你这一日（去了哪、得失、谁待你变了、接下了结的事、听来的消息）、该记着的生辰、江湖这一日、收到的帖子和节礼。跨年时接着弹一卷年谱。
- **书信**：江湖上有人找你时，会托人送来帖子或书信；拆开看，一键在剧情里提起。你寄出的信也在这里。
- **天时**：聊天跟着剧里的天气时辰变——清晨粉霞、正午天青、午后金黄、黄昏橙紫、入夜转暗；下雨飘雨丝，下雪落雪，还有雨夹雪、冰雹、风沙、热浪、霜露雾凇；晴夜有星星、银河、偶尔一颗流星，月亮按农历圆缺，阴天带晕；雨后黄昏火烧云。飘的花叶按月份换（正月梅、三月桃花柳絮、八月桂花、十月红叶……），夏夜有萤火。十八个节日、二十四节气各有样子：元日除夕的福字灯笼和烟花、上元的孔明灯、端午的艾草、七夕的银河喜鹊、中元的河灯、中秋的桂影、重阳的茱萸雁阵，惊蛰的春雷、芒种往天上飘的花、白露的露、霜降的霜、冬至的九九消寒图……印章上也挂个小物件。北境、西域、江南、蜀中各有风物（北境雪密、大漠风沙、江南梅雨、山间缠雾）。在屋里下雨只在窗边淌水珠、下雪窗角结霜；雨停了檐下滴水、白天挂彩虹；雪下久了输入框上沿积雪。可以画在酒馆背景图上、不压字；往回翻旧楼天色跟着那一楼；浓淡三档。「调天时」的时辰盘点一下就能改，下一楼 AI 也照着写。不挡字、不挡点，老手机自动减量。还可以开环境声：雨声、雷声、风声、夏秋夜里的虫鸣，在屋里发闷（默认关）。
- 界面上不再写「第几楼」，都写剧里的日子。
- **画像**：人物窗里点画像，交给柏宝绘或智绘姬画一张半身像，模型、画风和画幅都用它们里面的设置。长相按先后找：柏宝绘 / 智绘姬建档 → 角色卡和 Persona → 千千结人物档案 → 世界书 → 剧情，前面写明了的发色、发型、瞳色以前面为准，衣着以剧情里现在穿的为准；每一项都能在设置里关掉。提示词格式可选自然语言＋标签（NAI 5）或标签（NAI 4.5）。构思一次存下来，重画不再多花请求。也可以点「让 AI 读一遍」写成一段中文外貌自己改，或者上传自己的图。

## 天时脚本（不用碎影也能用）

碎影里的「天时」另外做成了一个酒馆助手脚本，任何角色卡都能用：聊天跟着剧情里的时辰、天气、节日节气、地方、月亮变，上面写的画面和声音都有。

**古代卡、现代卡、日式卡都能用**（江户、平安这类和风古代卡也行）：脚本自己看角色卡和最近几楼认出是哪种，认定了就记着，也能在设置里选。
- 现代卡按公历：春节、元宵、端午、七夕、中秋这些按公历日子推算出农历来过（自己按天文推算，不靠浏览器），还有元旦、情人节、国庆、万圣节、平安夜圣诞、跨年夜；二十四节气按那一年真实的日子；月亮按那天真实的圆缺。
- 日式卡：樱花季、梅雨、七八月的风铃、十月金木犀、红叶和银杏；正月的注连绳、女儿节、儿童节的鲤鱼旗、七夕竹和短册、盂兰盆的提灯和河灯、十五夜满月里的玉兔、万圣节的三角旗和蝙蝠、圣诞彩灯、大晦日。
- 和风古代卡按旧历过日本的老节（正月、女儿节、端午鲤鱼旗、七夕、盂兰盆、十五夜、大晦日），不过西洋节。
- 时间写「15:30」「下午三点半」「午後3時」「１５：３０」都认；天气认台风，也认「晴れのち雨」「曇り」「夕立」这类日文写法。现代卡、日式卡的时辰盘换成钟点盘。

**装法**：下载 [tianshi.json](https://github.com/Zaiyebuzuoyouqingdetiangou/syjh/raw/main/tianshi/tianshi.json)，在酒馆助手的脚本库里导入，打开就行。或者自己新建一个脚本，内容只写一行：

```
import 'https://testingcf.jsdelivr.net/gh/Zaiyebuzuoyouqingdetiangou/syjh/tianshi/tianshi.js';
```

**它从哪知道天时**：卡自带状态栏（`<时间>` `<天气>` 这类标签，或「时间：申时」一行一项）、MVU 变量，都自动认；卡什么都没有时，它让 AI 每楼开头写一行 `<天时>七月初九|申时|小雨|室外</天时>`（现代卡、日式卡写 `<天时>7月15日|15:30|小雨|室外</天时>`），并自动装一条正则把这一行藏起来（显示和发给 AI 时都去掉）。某一楼没写就沿用上一楼；删楼、重抽会对回那一楼。

**按钮**：输入框上面的按钮写着现在的天时（如「戌时·晴」），点开是时辰盘：改时辰和天气，下一楼 AI 照这个写；「设置」里有浓淡、画在背景上、花叶雨雪、月亮星星、往回翻跟着变、环境声，以及天时从哪读（自动 / 标签 / 变量 / AI 写）。

**其他**：过节那天会顺手告诉 AI 今天是什么节；世界书、状态栏模板里写 `{{天时}}` 会换成「八月十五 戌时 晴 屋外 满月」。不多发请求。碎影江湖在同一个聊天里开着天时时，脚本自己让开。

## 世界是活的

- **AI 记得**：每次生成前，插件把记下的江湖现状悄悄告诉正文的 AI——你身上的钱物、在场的人记得你做过什么、还没了结的事。NPC 不会忘了你欠的人情，钱也不会凭空多出来。发哪几段自己勾：时令、近况、在场的人、人情账、江湖传闻、暗线……不想让 AI 看的那段关掉就不发。
- **你看不见的地方也在动**：每过一个游戏日，不在场的人和各方势力也会有动向——有的变成江湖传闻，有的是你不知道的暗线，在合适的时候化作偶遇和后果回到剧情里。
- **江湖找上门**：隔三岔五有人找上门来——欠你人情的来道谢，你欠的来讨，记恨你的来寻仇，许久没见的来看你，也有冲着你名声来的生人；在路上就是偶遇。回复末尾弹一张帖子，写着谁、为什么来、带了什么，挑一个应对（或者自己写），发出去以后正文就写这件事。不理它，过了这天就散了。
- **名声**：你当众做的事会传开。各地的人怎么称呼你、听说过你什么，户帖和此地页都看得到；事迹还会慢慢传到别的城，到了那里，没见过你的人也可能认出你、议论你。
- **章回**：每过一日拟一副回目，往事簿就是你这段故事的章回目录。
- **节令与生辰**：端午、七夕、中秋这些节日和节气，卷轴里写时令风物，正文的 AI 也知道今天过节；户帖填了生辰，那天交好的人会送贺礼来，节日也有节礼，点「收下」放进信物。名册上谁的生辰到了，提前一天提醒你，顺带写他喜欢什么。
- **人生大事**：认识的人会成亲、升迁、远行、病倒，消息会传到你耳朵里，交情深的会送喜帖、讣闻。
- **庙会集市、天时异象**：哪座城在办庙会、灯会、比武招亲，此地页和舆图上标出来，能去凑的热闹并进「可做之事」；哪里闹暴雨大旱，赶路和物价跟着受影响。
- **月末邸报**：剧里每过一个月送来一份邸报（玩家是江湖月报）：朝野、江湖、坊间物价、风云榜，你做过传得开的事也会上报。
- **人情簿**：你欠谁、谁欠你、你应承过谁、谁记恨你，记账时自动记下，能手记、能勾掉；没了结的正文 AI 也记得。
- **待你变化、行旅图卷**：谁对你的态度跨了一档，回复末尾弹一张小卡写明因由；赶了路，弹一张路线小图和路上见闻。
- **关系网**：人物页「关系网」，你在正中，认识的人按待你远近一圈圈排开（亲近的、亲密过的在里圈，结怨的在外圈），线越红越粗交情越深；旁人之间的亲属、师门、情、主从、仇各用一种颜色连起来。能拖能捏，点人进人物页。下面一张「与你」：跟你是什么关系、待你如何、来往几回、亲密几次。
- **人物列传**：跟谁来往够深了，照史书笔法给他立一篇传，末尾「太史公曰」，人物窗「列传」里翻看。之后又有了来往能续写，只写新的、接在后面；也能照你说的补一段，插到合适的位置；不满意能撤回上一次。
- **回忆簿 / CG 相册**：剧情里有值得记住的一幕，回复末尾问一句。土著记进回忆簿，写成一页：那段回忆、那句话，能画一幅；回忆簿按月翻、能按人看。玩家收藏成剧情 CG，交给柏宝绘或智绘姬画横幅，相册里有收集率、分类，错过的能补收。在场的人记得跟你的共同回忆，正文 AI 也知道。
- 设置里可以看到此刻塞给 AI 的是什么；上面每一样都能在「江湖玩法」里单独关掉。

每条回复末尾有一张圆角折叠卡「此回所记」，收起时一颗小药丸写着这楼记了什么；点开以后，记错了可以当场撤销、补一条或重新提取。设置里可以关。

## 设置

面板右上角齿轮：

- **变化怎么记**：默认用主接口发一个小请求；也可以单独配一个便宜快的接口（可直接选酒馆里存好的连接，拉取模型后从下拉里选）。
- **安全阀**：正文截断（输出到上限、标签没写完）、接口报错、模型拒答或回复太短时，这楼不自动记账、不自动出图，不白花额度；文尾小条写明原因，写完了点「重新提取」照常记。设置里可以关掉。
- **标签过滤**：发给模型前去掉思维链、变量更新这类标签，可以扫描当前聊天里出现过的标签来勾选。
- **补建旧聊天**：已经聊了很多楼的存档，可以一键补建。前面的楼有三种补法：读记忆（碎影江湖自己的往事簿、心迹回廊的档案、柏宝书记忆、千千结、酒馆自带的总结、预设写在回复里的摘要、记忆世界书，读这些都不花钱，整理成起点只用一次请求；记忆没覆盖到的楼再分段读）、分段读原文、只读状态栏（完全不花钱）。补建在后台跑，关掉面板不影响；切到别的聊天会暂停，切回来自动接着做，刷新页面后也能接上。
- **迁档**：楼层太高太卡、开了新聊天，可以把旧档的整个江湖带过去——名册、来往、人情、名声、舆图、行囊、武功、近况，户帖、画像、回忆簿、列传都跟着走；新聊天里已经记过几楼也能迁，同名的人认成同一个。
- **存档**：导出、导入、清空。

## 数据放在哪

- 记录跟着聊天走，存在聊天文件里。删楼、换回复、开分支，记录会自动跟着回退。
- 接口、皮肤这类设置存在酒馆的扩展设置里。
- **更新插件不会清掉这些数据**；删掉插件再装回来，数据也还在。
- 手填接口地址时，密钥存在酒馆的扩展设置里。介意的话用酒馆自己的连接配置。

### 0.26.2 · 天时认得更多说法

- 天时认得台风（狂风暴雨），也认「15:30」「下午三点」这类钟点写法；「深夜一点半」不会再被当成下午。

### 0.25.2 · 画像和回忆画面按古代的头发衣着画

### 0.25.0 · 十八个节日、二十四节气、各地风物

### 0.24.1 · 印章时辰盘写上十二时辰

### 0.24.0 · 悬浮印章变成小时辰盘

- 悬浮印章换成一个小时辰盘：外圈是一天的天色（子时在上、午时在下），亮点停在现在的时辰；中间写着时辰的字，底色随天光变，下雨有雨丝、下雪有雪点、阴天发灰、起雾发白，晴夜挂个小月亮。
- 关掉「聊天跟着天气时辰变」时，聊天不变，印章照样跟着变；「调天时」也一直能用。还不知道几时几刻时，印章还是原来的「碎」「江」。轻点、长按、拖动都和原来一样。

### 0.23.0 · 天时大改

- 屋里屋外自动认：在屋里下雨，字上不飘雨，只在窗边淌水珠；下雪窗角结霜花；夜里屋里点着灯。
- 天气有前后：雨停后檐下还滴一阵水，白天放晴挂一道彩虹；雪下久了输入框上沿积起一层雪，停了慢慢化；风越大雨丝越斜。
- 飘的花叶按月份换：正月梅、二月杏、三月桃花和柳絮、四月蔷薇、五月榴花、七月梧桐叶、八月桂花、九月菊、十月红叶、腊月腊梅。

- 设置 → 天时 →「调天时」：时辰盘点一下就能改时辰和天气，下一楼也会悄悄告诉 AI 照这个写；「回到剧情」恢复。

### 0.22.4 · 时辰节日认得更准

### 0.22.3 · 天时更省电

### 0.22.2 · 天时看得出来了

- 聊天跟着天时变得更明显：清晨粉霞，上午、正午天青带日光，午后金黄，黄昏橙紫，入夜四角转暗，深夜更暗。浅色、深色主题都看得出，字照样看得清。

### 0.22.1 · 银两不再扣成负数，往事簿读得通

- 开局不知道身上带了多少钱时，银两显示「不详」，花钱不再扣成负数。账房会按你的身份家世估一个数（显示「约」），正文写明了身上有多少就换成实数。
- 行囊的钱袋旁边有「改」：直接写身上现有多少，之后的花销从这个数里扣。
- 往事簿重新切过：台词不再拦腰截断、引号配得上，你写的那几句不再挂「名字：」，句子不再用逗号硬串在一起；标题挑一句要紧的台词。旧的往事簿打开就会按新做法整本重切。

### 0.22.0 · 迁到新档

- 新聊天里已经记过几楼也能迁：同名的人认成旧档那一个，新认识的人发新号，不会串。

### 0.21.4 · 近况写短、不对的能去掉

- 近况六格每格写短一句，卡上截在句读上，不再半句话截断。
- 点近况里的体质或状态，可以说「不对，去掉」：不再显示，账房以后也不会再写到你身上。
- 账房只把正文明写在你本人身上的体质、伤病记给你，别人的不安到你身上。

### 0.21.3 · 江湖现状读起来像人话

- 告诉正文 AI 的江湖现状：句子不再拦腰截断；不写「打过65次交道」「亲密43次」这种次数，改成熟不熟、有没有过亲密。

- 近来的人事：同一个人的事传了几回只写最近一条，不再重复名字。取消、作罢的事不算没了结；邸报不再塞给正文。

### 0.21.2 · 近况会从正文补上

### 0.21.1 · 悬浮印章改小

### 0.21.0 · 回忆簿、CG 相册、列传续写

- 剧情里有值得记住的一幕（初见、救命、告别、并肩、节日、定情……），回复末尾问一句。土著点「记进回忆簿」，写成回忆簿的一页；玩家点「收藏」，生成一张剧情 CG。

- 生图写法照心迹回廊：NAI 5 自然语言或 NAI 4.5 标签，几个人的外貌和动作分开写；交给柏宝绘或智绘姬画横幅。
- 在场的人跟你有共同回忆时，正文 AI 也知道。人物页「与你」里能看到跟他的回忆。
- 设置里能调发现得多不多、土著记下时要不要顺手画一幅、要不要告诉正文 AI。
- 列传能续写（只写上回之后的新来往，接在后面）、补一段（照你说的写一段插到合适的位置）、撤回上一次；新来往多了会自己续一回。续写的、补的段落标出颜色。

### 0.20.2 · 合成一张卡
