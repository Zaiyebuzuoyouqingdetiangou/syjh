# 碎影江湖 · 酒馆插件

给角色卡「碎影江湖 · 资料片 刃影迷局」配的 SillyTavern 扩展。分**土著**与**玩家**两种模式：土著是这个世界的人（异人眼里的 NPC），玩家是进入江湖的异人。

## 安装

酒馆 → 扩展 → 安装扩展，填：

```
https://github.com/Zaiyebuzuoyouqingdetiangou/syjh
```

装好后聊天界面右下角会出现一枚印章：轻点打开面板，长按看速览，按住可以拖到别处。也可以输入 `/碎影` 打开。

## 有什么

| 页 | 土著 | 玩家 |
| --- | --- | --- |
| 舆图 / 地图 | 天下按大区分，城镇一行一个；点进城镇看去处、此地势力、在场的人。走过的地方越来越多，地图跟着长大，新出现的地点标「新」 | 同左 |
| 名册 | 没报过名的人只显示样貌；自称、化名、真名一层层解锁；写态度 | 写好感数值 |
| 行囊 / 背包 | 钱银、物件、信物、存款与欠账、成交、账目、手记 | 同左 |
| 江湖 | 风声与通缉、各方态度、时局、告示、百晓阁 | 通缉、阵营声望、世界公告、告示栏、情报 |
| 异闻 / 论坛 | 异人在他们的论坛上议论你——只有读者看得到 | 江湖论坛 |
| 户帖 / 角色 | 身份、所学武功、身体、心事 | 属性、状态、武学、任务、成就 |

每条回复末尾有一条可关的「本楼变化」，记错了可以当场撤销、补一条或重新提取。

## 设置

面板右上角齿轮：

- **变化怎么记**：默认用主接口发一个小请求；也可以单独配一个便宜快的接口（可直接选酒馆里存好的连接，拉取模型后从下拉里选）。
- **标签过滤**：发给模型前去掉思维链、变量更新这类标签，可以扫描当前聊天里出现过的标签来勾选。
- **补建旧聊天**：已经聊了很多楼的存档，可以一键补建；能读到记忆插件的话会先用记忆整理前面的部分。补建在后台跑，关掉面板不影响；切到别的聊天会暂停，切回来自动接着做，刷新页面后也能接上。
- **存档**：导出、导入、清空。

## 数据放在哪

- 记录跟着聊天走，存在聊天文件里。删楼、换回复、开分支，记录会自动跟着回退。
- 接口、皮肤这类设置存在酒馆的扩展设置里。
- **更新插件不会清掉这些数据**；删掉插件再装回来，数据也还在。
- 手填接口地址时，密钥存在酒馆的扩展设置里。介意的话用酒馆自己的连接配置。
