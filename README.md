# 碎影江湖 · 酒馆插件

给角色卡「碎影江湖 · 资料片 刃影迷局」配的 SillyTavern 扩展。分**土著**与**玩家**两种模式：土著是这个世界的人（异人眼里的 NPC），玩家是进入江湖的异人。

## 安装

酒馆 → 扩展 → 安装扩展，填：

```
https://github.com/Zaiyebuzuoyouqingdetiangou/syjh
```

装好后聊天界面右下角会出现一枚印章：轻点打开面板，长按看速览，按住可以拖到别处。也可以输入 `/碎影` 打开。

## 有什么

| 页 | 土著 | 玩家 |
| --- | --- | --- |
| 舆图 / 地图 | 一张手绘舆图：山川、官道、北境风雪、西域黄沙；你在哪盖一枚朱砂印，走过的路一笔笔连起来。开图先看走过的那一块，走得越远地图越大；剧情里新出现的城镇自动落在所属大区，标「新」。可以拖动、缩放，点城镇看详情，下面另有地名录。点开任何地方：此地风物、去处、归属与势力、在场和见过的人、能做的事、物价与买卖、传闻与事件、你的足迹 | 深色网格地图、定位标记、移动路线、探索进度；其余同左，叫法换成地点介绍、NPC、可交互、商店与物价、探索记录 |
| 名册 | 可以把人置顶；主角自己不会当成 NPC 列进来（认错了在人物页点「这是我」或「不是我」改过来）。没报过名的人只显示样貌；自称、化名、真名一层层解锁。点开人物：称呼与底细、对你（厌恶到亲密六档）、喜好与忌讳、关系网、近况、来往与亲密（按日期折叠） | 好感出数值（−100 到 +100），其余同左 |
| 行囊 / 背包 | 钱银、物件、信物、存款与欠账、成交、账目、手记 | 同左 |
| 江湖 | 风声与通缉、各方态度、时局、告示、百晓阁 | 通缉、阵营声望、世界公告、告示栏、情报 |
| 异闻 / 论坛 | 异人在他们的论坛上议论你——只有读者看得到 | 江湖论坛 |
| 户帖 / 角色 | 身份、所学武功、身体、心事 | 属性、状态、武学、任务、成就 |

## 像一个游戏

打开面板就是一整块游戏画面（土著参考太吾绘卷的水墨卷轴，玩家是深色网游界面）：

- **顶栏**：你的画像、银钱声名（玩家是气血内力），右边是剧里的日期、时辰、天气和节气。
- **此地**：你此刻所在的地方，水墨小景；这里站着谁（画像框，点开看人物）、能去哪、能做什么；传闻、手头的事、新来的书信。
- **人物窗**：画像、名号、身份、特性、待你如何、此刻在做什么。「生平」里按日子排着你和他的来往，还有你看不见的「暗里」——只有看戏的人知道。可以给人物换上自己的画像。
- **过日卷轴**：跨进新的一天，弹一张卷轴：你这一日、江湖这一日、收到的帖子。
- **书信**：江湖上有人找你时，会托人送来帖子或书信；拆开看，一键在剧情里提起。
- 界面上不再写「第几楼」，都写剧里的日子。

## 世界是活的

- **AI 记得**：每次生成前，插件把记下的江湖现状悄悄告诉正文的 AI——你身上的钱物、在场的人记得你做过什么、还没了结的事。NPC 不会忘了你欠的人情，钱也不会凭空多出来。
- **你看不见的地方也在动**：每过一个游戏日，不在场的人和各方势力也会有动向——有的变成江湖传闻，有的是你不知道的暗线，在合适的时候化作偶遇和后果回到剧情里。
- 设置里可以看到此刻塞给 AI 的是什么，也可以关掉。

每条回复末尾有一条可关的「本楼变化」，记错了可以当场撤销、补一条或重新提取。

## 设置

面板右上角齿轮：

- **变化怎么记**：默认用主接口发一个小请求；也可以单独配一个便宜快的接口（可直接选酒馆里存好的连接，拉取模型后从下拉里选）。
- **标签过滤**：发给模型前去掉思维链、变量更新这类标签，可以扫描当前聊天里出现过的标签来勾选。
- **补建旧聊天**：已经聊了很多楼的存档，可以一键补建；能读到记忆插件的话会先用记忆整理前面的部分。补建在后台跑，关掉面板不影响；切到别的聊天会暂停，切回来自动接着做，刷新页面后也能接上。
- **存档**：导出、导入、清空。

## 数据放在哪

- 记录跟着聊天走，存在聊天文件里。删楼、换回复、开分支，记录会自动跟着回退。
- 接口、皮肤这类设置存在酒馆的扩展设置里。
- **更新插件不会清掉这些数据**；删掉插件再装回来，数据也还在。
- 手填接口地址时，密钥存在酒馆的扩展设置里。介意的话用酒馆自己的连接配置。
